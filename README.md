# Rinari｜走進禮納里，看見國際

12 頁沉浸式視覺敘事網頁，使用原領營成果冊中的活動照片。

## 開啟網站

下載 `index.html`，以瀏覽器開啟即可。照片、樣式與 JavaScript 均內嵌在同一份檔案中，不需另外安裝套件。

第 9 頁為從臺灣出發的南島語族互動連線地圖，進入後自動巡覽，可暫停與手動選取；第 10 頁為部落之夜。

## 導覽

支援捲動、觸控、右側圓點、底部按鈕、方向鍵、Page Up/Down、Home/End。

## 資料來源

原始照片及課程資料：使用者提供的《原領營成果冊》。課程時數為規劃時數。
南島地圖為擴散區域示意，並非精確航路。

Robert Blust (2019), The Austronesian Homeland and Dispersal: https://doi.org/10.1146/annurev-linguistics-011718-012440

原住民族委員會，南島語族族群簡介：https://www.cip.gov.tw/zh-tw/news/data-list/49744114ECE41D1F/0C3331F0EBD318C2F69080C5C7060B21-info.html
